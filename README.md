# 🌍 WanderWise – Explore the World

## 📌 About the Project
WanderWise is a web-based tourist guide application that helps users explore popular tourist destinations across India, Japan, and China. It provides information about famous attractions along with images and descriptions through a simple and attractive interface.

## 🎯 Objectives
- Make exploring tourist destinations easier.
- Provide information about famous places around the world.
- Present destination details in an organized way.
- Create a simple and user-friendly travel exploration experience.

## ✨ Features
- Attractive homepage.
- About section.
- Country selection option.
- Separate pages for India, Japan, and China.
- Tourist attraction images and descriptions.
- Easy navigation between pages.
- Responsive destination card layouts.

## 🛠️ Technologies Used
- HTML5 – Website structure.
- CSS3 – Styling and page layouts.
- JavaScript – Page navigation.

## 🚀 How to Run
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `main1.html` in your browser or use Live Server.
4. Explore the different country pages.
